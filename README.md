A standalone, GitHub-compatible git forge in dependency-free TypeScript (Node.js standard library only): git smart HTTP (upload-pack protocol v2, receive-pack v0), the REST v3 API for repositories, contents, issues and pull requests, the GraphQL v4 API, and an MCP endpoint, all served from one in-memory store by a single process.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 node main.ts
```
